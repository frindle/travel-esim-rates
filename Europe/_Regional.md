## Coverage notes

- **Airalo (Eurolink)** — official page states **41 Countries and Networks** (fetched 2026-09-17
  directly from [airalo.com/europe-esim](https://www.airalo.com/europe-esim)). Note: an earlier pass of
  this repo recorded 42 countries for the same bundle; 41 is the currently-fetched figure and supersedes it.
  Exact country list not itemized on the plan page.
- **Holafly (Europe)** — **33 countries**, full list confirmed on-page: Andorra, Austria, Belgium,
  Bulgaria, Croatia, Cyprus, Czech Republic, Denmark, Estonia, Finland, France, Germany, Greece, Hungary,
  Iceland, Ireland, Italy, Latvia, Liechtenstein, Lithuania, Luxembourg, Malta, Netherlands, Norway,
  Poland, Portugal, Romania, Slovakia, Slovenia, Spain, Sweden, Switzerland, United Kingdom. Notably
  **excludes** Russia, Ukraine, Belarus, and the non-EU/EFTA Balkans (Serbia, Bosnia and Herzegovina,
  Albania, North Macedonia, Montenegro, Kosovo).
- **Nomad (Europe)** — page states **35–36 European countries** but does not itemize the full list
  (examples given: Austria, Belgium, France, Germany, Italy, Spain, UK, "and more"); page also notes
  coverage "may not include overseas territories" of member countries.
- **aloSIM (Europe)** — page states **35 countries / 51 networks**; exact country list not itemized on
  the plan page. aloSIM's unlimited day-pass tiers (3/5/7/10/15/30 days) are priced identically to
  Airalo's Eurolink tiers at every duration except 30 days ($72.50 vs $71.00) — plausibly the same
  underlying wholesale bundle resold, but not confirmed.
- **Saily — confirmed NO regional plan.** A cited review (eSIMTips) states explicitly: *"No regional
  plans — unlike Airalo, no multi-country plans for Europe or Asia travel. Each country requires a
  separate eSIM."* Recorded here as a negative finding so a build step doesn't need to keep re-checking
  for a Saily Europe row.
- **Ubigi, Maya Mobile, GigSky** — Europe-regional plan pages returned 404 or were JS-rendered with no
  plan data recoverable via fetch this pass; omitted rather than guessed (consistent with the JS-rendering
  gaps already noted for these providers elsewhere in this repo, e.g. GigSky in
  [providers.md](../providers.md)).
- **Jetpac** — the one row above is carried over from an earlier pass citing an aggregator review
  (thetraveler), not independently re-verified against Jetpac's own site this pass (its Europe plan page
  is JS-rendered and returned no plan data on fetch). Treat as ⚠️ approximate.

## Notes

- All Airalo, Holafly, and aloSIM regional rows are **unlimited-only day/duration passes** — no capped
  GB tier is offered by these three at the regional (multi-country) level, only at single-country level.
  Nomad is the only regional bundle here offering true capped GB tiers alongside unlimited passes.
- See the [Europe index](README.md) for single-country pages, and
  [Global/README.md](../Global/README.md) for worldwide (150+ country) passes — those are **not**
  duplicated here.

Note: eSIM coverage/carrier availability is thinner in parts of Africa — each country page's
**Carrier resolution** section flags which providers confirm a real local-network tie-in vs. those
that don't disclose one. Ethiopia in particular came back with several providers (Holafly, Saily, Maya
Mobile, Ubigi) returning no reachable country page at all — consistent with its history as a
state-telecom-monopoly market only recently opened to a second operator (Safaricom Ethiopia). See the
[root README](../README.md) for the rate-row format and confidence legend, and [providers.md](../providers.md)
for provider traits.
